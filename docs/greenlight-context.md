## What IS known: adjacent legacy-platform context

Unified Platform (UP) is documented as replacing three named legacy products,
and all clients must migrate off them:

- **MerchantView** (ex-EverC)
- **WebShield**
- **Single Platform** (legacy G2RS)

Replacement, not integration, is the confirmed goal — a UP capability isn't
considered done until it can move a real legacy customer off the product it
replaces. Where legacy capabilities overlap, UP must resolve to one behavior
as a product decision, not a merge.

**CONFIRMED (2026-09-09):** Greenlight is a fourth legacy platform, distinct
from MerchantView, WebShield, and Single Platform. It is not yet recorded in
this workspace's brains. UP's confirmed replacement mandate (client
migration, not integration) should be treated as applying to Greenlight the
same way it applies to the other three, pending confirmation from whoever
owns that mandate.
